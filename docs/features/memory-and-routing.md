# Memory, app cards and the intent router

Remembered facts and saved answers, the app cards the model is given, and the intent router in shadow mode. Part of the project rules (see `CLAUDE.md`).

## Memory, app cards, router

**Remembered facts and saved answers (C5, 2026-10-20).** Nothing is learned silently. *Remembered facts* (`Memory` in Core, `MemoryStore` in the app): one dated line per fact in `~/Library/Application Support/ClickBait/NOTES.md`, added only by the user — spoken or typed "remember / remember that / don't forget / keep in mind / from now on / note that I…", right-click ▸ Services ▸ Remember with ClickBait on highlighted text, or the chat header's brain button (both show the line in an editable alert first). "forget …" removes lines. Newest wins about the same thing ("my team is …", "I use …"); passwords, PINs, keys, tokens, card numbers and identity numbers (US SSN, Singapore NRIC/FIN, passport-style, IBAN, bank account words; `PersonalData`, 2026-10-21, idea from Sentient OS) are refused — the same identity numbers are also taken out of Internet Mode search words (`QueryScrubber`); 30 lines at most. A plain ask gets the lines that share a word with it first, then the newest, ≤600 characters (`AskRequest.remembered`). Menu: Remembered… opens the file. *Notes folder* (`NoteFolder` in Core, `MemoryStore.notes`; 2026-10-21, idea from Sentient OS): every `.md` file in `~/Library/Application Support/ClickBait/Notes/` (newest first, ≤100 files of ≤256 KB, read fresh per question) — lines that share a word with the question, minus headings and anything `Memory.looksSecret` flags, go in after the remembered facts as "From the user's notes", each with its file name, ≤800 characters (`MemoryStore.block(for:)` → `AskRequest.remembered`). Menu: Notes Folder… opens it in Finder. No reader or map yet. *Saved answers* (`SavedAnswer` in Core, `AnswerArchive`): the chat header's save button writes the chat (text only) to `~/Library/Application Support/ClickBait/answers/<date> <question>.md`, never overwriting, and shows it in Finder; menu: Saved Answers…. A new Services item may only appear after logging out and in.

**App cards (C4, 2026-10-20).** `AppCards` (Core): 15 short notes (≤1,200 characters each; menus and shortcuts only, checked for macOS 26) — Notes, Reminders, Finder, Safari, Google Chrome, Mail, Calendar, Messages, System Settings, Preview, Music, Photos, TextEdit, Terminal, Maps. One goes into the prompt when the request names its app the user's way (`TutorialQuestion.locatingApp`: "in Notes", "open Safari"; "my notes" is not the app), and into walkthrough planning for the named app or else the app in front. Mail, Messages and Terminal cards say ClickBait never sends or runs anything; System Settings says security switches are the user's. When macOS moves a menu, fix the card.

**IntentRouter — shadow mode (C3, 2026-10-20).** After each spoken question ends and ClickBait is idle for 1.5 s, a text-only request (`routeIntent`, `Prompt.routeSystem`, Ollama schema `{intent: answer|point|tutorial|order|clarify, app}`, 40 tokens, 3 s timeout) sorts the question; the reply is checked (`IntentRouter.parse`: known intent, app only if installed), retried once if bad, cached (200), and logged next to what ClickBait did: `Router (shadow): said tutorial (System Settings), ClickBait did answer: differs in 0.6 s`. It changes nothing and never runs while ClickBait is busy. Off: `defaults write org.clickbait.ClickBait router.shadow -bool false`. Next: read the log, then let it decide one intent at a time.
